## 🚀 快速开始

### 首次使用

1. **访问应用**
   - 打开浏览器访问 `http://localhost:3000`

2. **配置 AI 服务**
   - 点击左侧菜单「设置」
   - 点击「添加服务」按钮
   - 选择 AI 服务提供商
   - 填写 API Key
   - 点击「测试连接」验证
   - 保存配置

3. **开始创作**
   - 前往「文生图」页面
   - 输入提示词
   - 点击「开始生成」

## ⚙️ AI 服务配置

### 支持的服务提供商

#### 1. OpenAI (DALL-E)

**获取 API Key**:
- 访问 https://platform.openai.com
- 注册并登录
- 前往 API Keys 页面
- 创建新的 API Key

**配置步骤**:
1. 提供商：选择「OpenAI (DALL-E)」
2. 服务名称：自定义（如"我的 OpenAI"）
3. API Key：粘贴你的 OpenAI API Key
4. 模型：选择 `dall-e-3`（推荐）或 `dall-e-2`
5. 最大并发数：默认 50

#### 2. 阿里百炼（通义万相）

**获取 API Key**:
- 访问 https://bailian.console.aliyun.com/
- 开通通义万相服务
- 获取 API Key

**配置步骤**:
1. 提供商：选择「阿里百炼（通义万相）」
2. 服务名称：自定义
3. API Key：粘贴你的阿里云 API Key
4. 模型：默认 `wanx-v1`

#### 3. 中转站

**适用场景**:
- 使用第三方 API 中转服务
- 自建的 Stable Diffusion 服务

**配置步骤**:
1. 提供商：选择「中转站」
2. Base URL：填写中转站地址
3. 中转站类型：
   - OpenAI 格式：兼容 OpenAI API
   - Stable Diffusion 格式：SD WebUI API
4. API Key：根据中转站要求填写

## 🎨 文生图

### 基础使用

1. **输入提示词**
   ```
   示例：一只可爱的橘猫坐在窗台上，阳光洒进来，温馨的家居场景，高质量摄影
   ```

2. **负向提示词（可选）**
   ```
   示例：模糊，低质量，变形，多余的肢体
   ```

3. **配置参数**
   - **尺寸**：选择预设尺寸或自定义
   - **生成数量**：1-4 张
   - **采样步数**：10-50（越高质量越好，但越慢）
   - **CFG Scale**：1-20（越高越严格遵循提示词）
   - **随机种子**：固定种子可重现结果

4. **开始生成**
   - 点击「开始生成」按钮
   - 等待生成完成（通常 10-60 秒）
   - 结果自动保存到资源库

### 提示词技巧

**好的提示词结构**：
```
[主体] + [动作/状态] + [环境] + [风格] + [质量词]

示例：
商品主图，白色背景，iPhone 手机，正面展示，专业摄影，高清，细节丰富
```

**常用质量词**：
- 高质量：`high quality`, `detailed`, `sharp focus`
- 摄影风格：`professional photography`, `studio lighting`
- 艺术风格：`illustration`, `digital art`, `oil painting`

## 🖼️ 图生图

### 基础使用

1. **上传原图**
   - 点击上传区域
   - 或拖拽图片到上传区域

2. **输入提示词（可选）**
   - 描述你想要的变化方向
   - 留空则生成相似变体

3. **调整参数**
   - **变化强度**：0-1
     - 0.3-0.5：轻微变化，保留大部分原图
     - 0.6-0.8：中等变化，平衡原图与提示词
     - 0.8-1.0：大幅变化，主要遵循提示词
   - 其他参数同文生图

4. **开始生成**

### 应用场景

- **产品图优化**：提升商品图质量
- **背景替换**：更换产品背景
- **风格转换**：改变图片风格
- **细节增强**：提升分辨率和细节

## 🔄 工作流编排

### 概念介绍

工作流允许你将多个操作串联起来，实现自动化的图片处理流程。

### 节点类型

#### 输入节点
- **文本输入**：输入提示词
- **图片输入**：上传图片
- **参数输入**：输入数值

#### AI 处理节点
- **文生图**：根据文本生成图片
- **图生图**：基于图片生成新图片
- **背景移除**：移除图片背景

#### 图片处理节点
- **裁剪**：裁剪图片
- **缩放**：调整尺寸
- **滤镜**：应用滤镜效果

#### 逻辑节点
- **条件判断**：根据条件分支

#### 输出节点
- **输出**：保存结果到资源库

### 创建工作流

1. **添加节点**
   - 从左侧节点面板拖拽
   - 或在画布空白处点击

2. **连接节点**
   - 从输出端点拖拽到输入端点
   - 创建数据流

3. **配置节点**
   - 点击节点
   - 在右侧属性面板配置

4. **执行工作流**
   - 点击「执行」按钮
   - 查看执行结果

### 保存与加载

- **保存**：保存为 JSON 文件
- **加载**：从 JSON 文件加载

## ❓ 常见问题

### Q: 生成速度很慢？
**A**: 
- 检查网络连接
- 降低采样步数
- 减少生成数量
- AI 服务响应时间因提供商而异

### Q: 生成失败怎么办？
**A**:
- 检查 API Key 是否有效
- 检查账户余额/配额
- 查看错误提示信息
- 尝试重新连接

### Q: 如何提高生成质量？
**A**:
- 使用详细的提示词
- 增加采样步数
- 调整 CFG Scale
- 尝试不同的 AI 服务

### Q: 资源库图片无法显示？
**A**:
- 检查 `user-data` 目录权限
- 确认图片文件存在
- 检查浏览器控制台错误

### Q: 如何备份数据？
**A**:
- 备份 PostgreSQL 数据库
- 备份 `user-data` 目录
- 导出工作流为 JSON

### Q: 支持哪些图片格式？
**A**:
- 上传：JPG、PNG、WEBP
- 生成：PNG（默认）
- 导出：PNG、JPEG

### Q: 最大并发数如何设置？
**A**:
- 根据 API 提供商限制设置
- OpenAI：建议 10-20
- 阿里百炼：建议 20-50
- 过高可能导致限流

创建常用提示词模板：
```

{商品名称}，白色背景，正面展示，专业摄影，高清，细节丰富

营销海报模板：
{主题}，创意设计，视觉冲击，现代风格，高质量

场景图模板：
{商品} 在 {场景} 中，{氛围}，专业摄影，高清
```

### 2. 工作流模板

常用工作流：
- **批量生成**：文本输入 → 文生图 → 输出
- **图片优化**：图片输入 → 图生图 → 缩放 → 输出
- **背景替换**：图片输入 → 背景移除 → 文生图 → 合成 → 输出

建议的文件夹结构：
```
- 商品主图
  - 服装类
  - 电子类
  - 食品类
- 营销素材
  - Banner
  - 海报
  - 详情页
- 原始素材
```
