# 无限画布滚轮交互修复文档

## 修复范围

- 无限画布滚轮缩放方向。
- 无限画布区域滚轮触发页面滚动的问题。

## 问题一：缩放方向相反

### 现象

鼠标滚轮向下时画布放大，向上时画布缩小，与常见设计工具的操作习惯相反。

### 原因

当前缩放系数直接使用 `deltaY`：

```ts
const factor = Math.pow(1.1, e.deltaY / 100);
```

滚轮向下时 `deltaY > 0`，导致缩放比例变大。

### 修复方案

反转 `deltaY` 的符号：

```ts
const factor = Math.pow(1.1, -e.deltaY / 100);
```

### 验收标准

- 滚轮向上：以鼠标位置为中心放大。
- 滚轮向下：以鼠标位置为中心缩小。
- 缩放范围仍限制在 `0.05 ~ 5`。

## 问题二：滚轮带动整个页面

### 现象

鼠标位于无限画布区域滚动时，浏览器页面会发生上下滚动；节点表单区域滚动到边界后尤为明显。

### 原因

画布缩放需要通过 `preventDefault()` 阻止浏览器默认滚动。节点内部为支持表单滚动而跳过该调用时，滚动事件会继续触发页面默认滚动。

### 修复方案

普通画布区域拦截默认滚动并执行缩放：

```ts
e.preventDefault();
// 执行画布缩放
```

节点表单区域允许内部滚动，但阻止滚动链传递到页面：

```tsx
<div data-canvas-scroll className="overflow-y-auto overscroll-contain">
```

画布视口同样限制滚动链：

```tsx
<div className="touch-none overscroll-contain">
```

### 验收标准

- 鼠标位于空白画布或图片图层时：只缩放画布，页面不滚动。
- 鼠标位于节点参数表单时：只滚动节点内部内容，页面不滚动。
- 节点内部滚动到顶部或底部后：页面仍不发生滚动。
- 触控板滚动与普通鼠标滚轮行为一致。
