# ADR-0001：联网搜索服务选型与接入

> **状态**：已批准（2026-08-13）
> **决策者**：研发
> **影响模块**：联网 GEO（Phase 7）、市场洞察（Phase 7）
> **关联文档**：`商图策AI营销内容模块研发实施设计文档V3` 第 9.4 节

## 背景

V3 设计文档要求：联网 GEO 和市场洞察开始前必须形成搜索服务 ADR，明确供应商、查询限额、成本归属、缓存 TTL、来源去重、页面抓取、引用展示、隐私、敏感行业和失败降级。没有已启用且实测通过的搜索服务时，市场洞察不可提交，联网 GEO 不可开启。

## 决策

### 1. 供应商与协议

- **主协议**：OpenAPI 风格 JSON 搜索接口（`POST /search` 或 `GET /search`，返回 `results[{title,url,content}]`）。
- **默认供应商**：Tavily（`https://api.tavily.com/search`，POST JSON）。
- **备选兼容**：Serper（`https://google.serper.dev/search`，POST JSON）。
- **自定义**：用户可配置任意符合"输入 query → 输出 results 列表"的 JSON 接口。
- 解析策略：按 `provider` 分别映射响应结构（tavily/serper），`custom` 走通用映射（直接读取 `results` 数组，容错 `data.results`/`organic`）。
- **不使用**模型训练记忆替代实时搜索；搜索结果必须来自搜索服务 HTTP 响应。

### 2. 密钥与成本归属

- 搜索服务 API Key 由**用户自行申请并在设置页配置**，密钥仅加密保存在服务端 `SearchServiceConfig.apiKeyEncrypted`。
- 成本由用户的搜索服务账户承担；本项目不做账单代理。

### 3. 查询限额

- 每次市场洞察任务最多 **12 次**搜索查询（`maxQueriesPerTask`，默认 12，设置页可调 1-20）。
- 联网 GEO 每次任务最多 **5 次**搜索查询。
- 超限时停止后续查询，以已获结果生成，并在结果中标记"查询配额已用尽"。

### 4. 缓存与去重

- 进程内查询结果缓存：**TTL 6 小时**，key = `provider + query 归一化`；同一查询在 TTL 内不重复调用上游。
- 来源去重：按 URL 去重；同一域名最多保留 3 条结果。

### 5. 页面抓取

- **第一版不抓取页面正文**，仅使用搜索服务返回的标题与摘要（snippet/content 字段）。
- 避免抓取带来的合规与成本风险；后续如需正文引用，需单独评审（含 robots、版权与限流）。

### 6. 引用展示与数据时效

- 联网结果必须携带 `sources[{title,url,snippet,retrievedAt}]`，前端与导出均展示来源 URL 与抓取时间。
- 结果固定展示数据时效声明："以上信息来自联网搜索，检索时间 {时间}，内容可能过时"。
- 无来源或查询失败时：结果标记 `degraded: true` 并明确提示"未能获取联网信息，以下内容仅基于本地事实"。

### 7. 隐私

- 仅发送用户主动输入的查询词（商品名、关键词、问题），不发送用户身份信息、API Key 之外的敏感数据。
- 查询词在日志中脱敏输出（截断）。

### 8. 敏感行业

- 医疗、金融、法律等敏感行业的洞察结果不构成专业建议；前端与导出固定附加免责声明。
- 不做任何行业黑名单过滤（用户自有内容），只做展示层声明。

### 9. 失败降级

- 搜索服务不可用/超时/限流：任务不整体失败，以 `degraded` 结果返回（仅本地事实），错误详情记录到任务 error。
- 重试：单个查询最多 1 次重试（网络错误/429/5xx），指数退避。

## 落实方式

- `src/lib/search/SearchAdapter.ts`：接口 + `HttpSearchAdapter` 实现 + 缓存/去重/限额。
- `SearchServiceConfig`（Prisma）：配置 CRUD 与实测（实测 = 一次真实查询"保温杯"返回含 URL 结果即通过）。
- 营销引擎的 `ModelCapabilities.webSearch` 仅作展示标签；路由依据 = 存在已启用且 `testStatus=passed` 的 SearchServiceConfig。

## 后果

- 正面：市场洞察与联网 GEO 可获得真实、可追溯的联网结论；无配置时明确降级，不误导用户。
- 负面：依赖第三方搜索服务稳定性与费用；6 小时缓存可能返回非实时数据（结果中已声明检索时间）。
