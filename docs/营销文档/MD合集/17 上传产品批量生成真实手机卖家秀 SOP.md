# 17 上传产品批量生成真实手机卖家秀 SOP

[7月2日 买家秀\.mp4](图片和附件/7月2日%20买家秀.mp4)

**适用场景**

这份 SOP 用于把用户上传的产品图，批量生成一组像真实手机拍出来的卖家秀图片。

适合：

1. 电商商品上架前补充生活化卖家秀。

2. 小红书、抖音、视频号、朋友圈、私域素材里需要“真实使用感”的产品图。

3. 同一个产品批量生成多个生活场景。

4. 多个产品统一生成同一种真实手机拍照风格。

**不适合：**

1. 平台首图白底图。

2. 详情页信息海报。

3. 带大段文字、卖点排版、参数表、促销标签的设计图。

4. 夸张棚拍、大片广告、奢侈品杂志大片风格。

## 核心目标

生成结果必须像真实手机随手拍出来的商品卖家秀，而不是 AI 精修广告图。

关键标准：

1. 产品外观真实：颜色、结构、比例、包装、标签、材质和可见细节必须以上传产品图为准。

2. 场景真实：像日常家里、桌面、包里、车内、办公室、厨房、浴室、卧室、户外轻使用等真实环境。

3. 拍摄真实：使用手机拍照质感，有自然环境光、轻微手持感、真实接触阴影、合理景深和不过度完美的构图。

4. 批量稳定：每张图场景不同，但产品不能变形、变色、换包装、加不存在的配件。

5. 不能广告化：不要变成电商海报、棚拍大片、详情页模块、3D 渲染图或过度精修商业图。

## 使用素材

必传：

1. 产品图：建议上传清晰正面图、侧面图、包装图或细节图。

可选补充：

1. 产品名称：

2. 产品用途：

3. 目标用户：

4. 生成数量：默认 8 张。

5. 画幅比例：默认 `3:4`，也可用 `1:1`、`4:5`、`9:16`。

6. 是否允许人物：默认只允许手部、身体局部、背影、下巴以下裁切，不允许可识别人脸。

7. 场景偏好：例如居家、办公室、户外、车内、厨房、浴室、卧室、桌面、包内。

8. 不要出现的场景或元素：

## 第一步：生成批量卖家秀生图提示词

把产品图上传给多模态 AI，然后复制下面这段提示词。

你是一名真实手机买家秀拍摄导演、电商生活化内容摄影策划师和 AI 生图提示词专家。



我会上传一张或多张产品图。你的任务不是生成广告海报，也不是做棚拍大片，而是根据上传产品图，为这个产品批量生成一组“相同场景下的真实手机买家秀”生图提示词。



【输入参数】

产品名称：如未提供，请根据上传产品图保守识别

生成数量：【 6 张】

画幅比例：3:4

人物规则：默认可出现手部、身体局部、背影、下巴以下裁切，不允许可识别人脸

固定场景：如果用户未指定，请根据产品品类自动选择一个最合理的单一真实生活场景，并在整组图片里保持一致

风格关键词：真实手机拍照、自然光、生活化、轻微手持感、不过度摆拍、干净但不棚拍



【核心任务】

请根据上传产品图，按【生成数量】输出对应数量的中文生图提示词，每条都必须可直接复制到 AI 生图工具里使用。

每条提示词对应一张买家秀图片。

整组图片必须发生在同一个固定生活场景里，保持同一房间、同一背景材质、同一台面或承托物、同一光线方向、同一色温、同一套生活道具和同一手机拍摄质感。

整组图片之间的差异只能来自同一场景内部的拍摄变化，例如产品角度、手持动作、拍摄距离、局部特写、开箱状态、自然遮挡、前后景关系和轻微构图变化。

不要把整组图片写成不同场景，不要一张厨房、一张户外、一张车内、一张办公室。

除【输入参数】里的“生成数量”一行外，不要在后续页面标题、每条生图提示词正文、负面约束或结尾参数里再次写出具体数量。

重要硬规则：这里的“手机拍照质感”只表示照片像用手机拍出来，不表示画面中需要出现手机。除非上传产品本身就是手机、手机壳、数据线、充电器、手机支架、手机挂绳等手机相关商品，否则画面里严禁出现手机、iPhone、手机屏幕、手机摄像头模组、手机壳、平板、相机或其他无关电子设备。



【后台静默执行，不要输出分析过程】

1. 识别上传产品的真实品类、外观、结构、颜色、材质、包装、品牌露出、标签、尺寸感和可见细节。

2. 判断这个产品最适合出现在哪一个真实生活场景里。

3. 先确定一段“固定场景基准描述”，包括房间/空间类型、台面或背景材质、主要道具、光线方向、色温、画面干净程度和手机拍摄风格。

4. 把同一段固定场景基准描述复制并改写到每条生图提示词里，保证整组图看起来像同一个买家在同一个地方连续拍摄。

5. 按【生成数量】规划同场景内互不重复的买家秀图片，避免只改变背景，也避免每张换场景。

6. 每张图都必须像普通手机拍摄出来的真实照片，不要像设计师摆拍的广告大片。

    

【产品锁定规则】

1. 必须以上传产品图作为唯一产品外观依据。

2. 严格保持产品真实品类、轮廓、比例、结构、颜色、材质、包装、品牌露出、标签和所有可见细节不变。

3. 不得把产品改成别的款式、别的颜色、别的包装、别的容量、别的型号。

4. 不得新增上传产品图中没有的配件、赠品、功能、认证、屏幕内容、图案或品牌信息。

5. 如果产品图里看不清某个信息，只能保守处理，不能脑补。

    

【固定场景规则】

1. 整组图必须共用同一个真实生活场景。

2. 同一个场景要具体到空间和材质，例如“窗边浅木色书桌”“浴室白色洗手台”“厨房灰色石英石台面”“卧室床边浅色床单”“车内副驾驶座位”“办公室白色桌面”。

3. 整组图中的背景、台面、主光方向、色温、道具体系和整体生活痕迹必须一致。

4. 道具可以轻微移动，但必须是同一套道具，不要每张图换一批道具。

5. 可以变化镜头距离、拍摄角度、产品朝向、手部动作、开箱状态、局部细节和自然裁切。

6. 禁止把整组图拆成多个场景，禁止一张居家、一张户外、一张车内、一张办公室。

    

【真实手机拍照质感规则】

1. 画面必须像手机实拍照片：手机 1x 或 2x 镜头视角、自然环境光、轻微手持构图、自动曝光、真实白平衡、轻微生活噪点、自然压缩质感。

2. 构图可以稍微不完美，例如轻微偏中心、自然裁切、桌面边缘可见、背景有少量生活痕迹，但整体必须干净可用。

3. 光线使用同一个真实环境光来源，例如同一侧窗光、同一盏室内顶灯、同一段傍晚柔光、同一方向的手机随手拍柔和阴影。

4. 产品必须有真实接触阴影、合理透视和真实尺度，不能悬浮、变形或像 3D 模型。

5. 不要过度磨皮、过度锐化、过度景深、过度电影光、过度商业精修。

6. “手机实拍照片”是拍摄质感描述，不是道具描述。非手机类产品的画面里不要出现任何手机或手机相关配件。

    

【买家秀场景规则】

1. 固定场景必须与产品真实用途匹配。

2. 可以选择一个真实生活场景：桌面、床边、沙发、厨房台面、浴室洗手台、梳妆台、办公室桌面、包内、车内、门口玄关、咖啡桌、收纳柜等。

3. 场景一旦确定，整组图都必须围绕这个场景拍摄，不得切换到其他空间。

4. 可以加入少量真实生活道具，但道具只能服务生活感和尺度感，不能喧宾夺主。

5. 道具中默认禁止手机、iPhone、平板、相机、耳机盒等容易抢占画面的电子设备，除非它们就是上传产品或与上传产品真实用途强相关。

6. 不要生成豪华摄影棚、广告布景、夸张道具、大片灯光、超现实场景或不符合普通人日常的空间。

7. 图中不要出现无关文字、乱码、水印、平台 Logo、价格标签、促销贴纸、参数卡片或详情页排版。

    

【人物规则】

1. 默认允许出现手部、手臂、肩部以下身体局部、背影、下巴以下裁切、穿戴局部、使用动作。

2. 默认不允许出现可识别人脸、正脸、半张脸、明星脸、过度精修模特脸。

3. 如果产品需要人物使用，只呈现自然使用动作，不要拍成模特广告大片。

4. 人物皮肤、手部、服装和产品接触关系要真实，不能穿帮、融合、变形或遮挡产品核心信息。

    

【同场景批量差异规则】

整组图片之间必须有明确差异，但差异只能发生在同一场景内，可以从以下方向选择：

1. 同一场景全貌随手拍

2. 同一场景手持展示

3. 同一台面平放展示

4. 同一场景使用中局部

5. 同一场景包装和产品合影

6. 同一场景开箱过程

7. 同一场景尺寸参照

8. 同一场景细节近拍

9. 同一场景不同产品朝向

10. 同一场景轻微前景遮挡

    

【输出格式】

只输出与【生成数量】一致的最终生图提示词，不要输出分析、解释、教程或注意事项。

每条用以下格式。页面标题只写主题，不要在标题里写“共几张”或重复生成数量：



页面一：买家秀主题标题

【完整生图提示词】



页面二：买家秀主题标题

【完整生图提示词】



页面编号按实际输出顺序自然递增，输出到【生成数量】对应的最后一页即可，不要额外写数量说明。



每条生图提示词都必须包含：

1. 以上传产品图作为唯一产品外观依据

2. 同一个固定真实生活场景，并在每条提示词里重复这个场景基准

3. 产品位置、角度、占比和接触关系

4. 手机拍摄质感描述

5. 同一光线、同一背景、同一道具体系、景深和自然瑕疵

6. 产品不变形、不变色、不新增信息的约束

7. 不要文字、水印、海报排版、棚拍广告感、3D 渲染感、无关手机道具和无关电子设备的负面约束

8. 统一结尾：real smartphone photo, user\-generated buyer show, same scene series, natural ambient light, handheld composition, realistic scale, product accurate, no poster design, no watermark, \-\-ar 3:4

## 第二步：批量生成卖家秀图片

### 同一个产品批量生成多场景

操作：

1. 打开三万图 AI 或其他支持批量任务的生图工具。

2. 上传同一组产品图。

3. 把第一步输出的 `页面一` 到 `页面八` 在拆页模式粘贴。

4. 如果某一张翻车，只返修那一张，不要整组重做。

### 多个产品统一生成同风格卖家秀

如果要给多个产品生成同一种真实手机卖家秀风格，可以使用多配一模式，把多张产品图配同一条通用提示词：

```Plain Text
以上传产品图作为唯一产品外观依据，严格保持产品真实品类、轮廓、比例、结构、颜色、材质、包装、品牌露出、标签和所有可见细节不变；为该产品生成一张真实手机拍照质感的卖家秀照片，场景由产品真实用途自动决定，必须是普通人日常生活中合理出现的环境，例如桌面、家中、办公室、厨房、浴室、卧室、包内、车内或户外轻使用场景；产品自然出现在画面中，占画面约 35%-60%，有真实接触阴影、合理透视和真实尺度，可以有少量生活道具和自然背景杂物，但整体干净可用；画面像手机 1x 或 2x 镜头随手拍摄，自然环境光、轻微手持构图、自动曝光、真实白平衡、轻微生活噪点、自然压缩质感，不要棚拍广告感，不要商业海报感，不要过度精修，不要 3D 渲染感；默认不出现可识别人脸，只允许手部、身体局部、背影或下巴以下裁切；不要生成无关文字、乱码、水印、平台 Logo、价格标签、促销贴纸、参数卡片、详情页排版；不要改变产品外观，不要新增产品图中没有的配件、功能、规格、认证、屏幕内容、品牌信息或包装文字。real smartphone photo, casual seller show, natural ambient light, handheld composition, realistic scale, product accurate, no poster design, no watermark, --ar 3:4
```

## 类目适配建议

服饰配饰：

1. 优先使用镜前半身局部、衣架旁、床边搭配、手持细节、穿戴局部。

2. 默认不露脸，避免生成网红棚拍。

美妆日化：

1. 优先使用梳妆台、浴室洗手台、手持瓶身、包内随拍、局部质感近拍。

2. 不要编造功效、成分、容量和试用前后对比。

食品饮料：

1. 优先使用厨房台面、餐桌、办公室零食角、手持包装、真实开袋/摆盘。

2. 不要编造口味、产地、营养数据、认证和促销文案。

家居百货：

1. 优先使用客厅、厨房、浴室、收纳柜、桌面、床边、玄关等真实空间。

2. 强调真实尺度和使用关系，不要变成样板间广告图。

3C 数码：

1. 优先使用办公桌、床头、车内、背包、手持使用、充电场景。

2. 不要生成不存在的屏幕界面、接口、灯效、品牌型号或功能效果。

## 验收清单

每张卖家秀生成后检查：

1. 产品是否与上传图一致，没有变色、变形、换包装、换结构。

2. 是否像真实手机拍照，而不是棚拍广告图、详情页图、3D 渲染图。

3. 场景是否真实合理，和产品用途匹配。

4. 光线、阴影、尺度、透视是否自然。

5. 是否没有无关文字、乱码、水印、促销标签、平台 Logo。

6. 是否没有可识别人脸，除非你明确允许露脸。

7. 批量图片之间是否有差异，而不是只换背景。

8. 产品核心信息是否清楚，没有被手、道具或背景遮住。

## 常用返修提示词

### 太像广告棚拍

```Plain Text
请把这张图改得更像真实手机随手拍的卖家秀照片。降低棚拍广告感和商业精修感，保留上传产品外观不变，使用自然环境光、轻微手持构图、真实生活背景、自然接触阴影和不过度完美的手机照片质感。不要海报排版，不要大片灯光，不要 3D 渲染感。
```

### 产品变形或变色

```Plain Text
请只修正产品外观。产品必须严格以上传产品图为准，恢复原本颜色、结构、比例、材质、包装、标签和可见细节。场景和手机拍照质感可以保留，但不要改产品款式、颜色、包装、配件或功能。
```

### 场景太假

```Plain Text
请把场景改成普通人真实生活中会出现的环境，减少豪华布景、夸张道具和广告大片感。产品仍然保持清晰可见，场景可以是桌面、家中、办公室、包内、车内、厨房、浴室或卧室等真实日常空间，整体像手机真实拍摄。
```

### 人脸太明显

```Plain Text
请移除可识别人脸，只保留手部、身体局部、背影或下巴以下裁切。不要出现正脸、半张脸、明星脸或过度精修模特脸。产品外观和真实手机拍照质感保持不变。
```
