## [20:42:00] 修复设置页按钮无法交互（局域网访问 JS 被阻断）

- **修改说明**：设置页在通过局域网 IP（172.26.224.1:8600）访问时所有按钮无法点击。定位为 Next.js 16 开发模式默认只放行 localhost，从其他来源请求 `/ _next/static/chunks/*.js` 与 `/_next/hmr` 会被 `allowedDevOrigins` 安全机制阻断（服务端日志出现 8 条 "Blocked cross-origin request ... from 172.26.224.1"），导致页面只剩 SSR 静态 HTML、React 未 hydration、所有事件失效。修复方式：在 `next.config.ts` 中配置 `allowedDevOrigins` 放行本机全部局域网地址。同时排查出 PostgreSQL 未运行（5432 无监听，`/api/model-configs` 报 PrismaClientInitializationError），已通过 `docker compose up -d postgres` 启动容器并确认迁移已应用。重启 dev server（端口 8600）后验证：局域网页面加载无报错、按钮点击对话框正常弹出/关闭、Tab 切换正常、`/api/model-configs` 返回 200。
- **受影响文件**：
  - `next.config.ts`（新增 `allowedDevOrigins` 局域网地址列表）

## [21:00:00] 修复保存模型报 crypto.randomUUID is not a function

- **修改说明**：设置页点击「保存」时抛 `crypto.randomUUID is not a function`。原因是 `crypto.randomUUID` 仅在安全上下文（HTTPS/localhost）可用，通过局域网 IP 的 HTTP 页面访问时该 API 不存在。在 `src/lib/utils.ts` 新增 `generateId()`：优先使用原生 `crypto.randomUUID`，不可用时用 `crypto.getRandomValues`（非安全上下文也可用）手写 UUID v4 兜底；替换全部 6 处客户端调用（设置页保存、useConfigStore 添加/导入、useTextModelStore 保存/添加/迁移）。服务端 API 路由使用的 `node:crypto` 不受影响。已用浏览器实测：填写表单 → 保存 → 对话框关闭且新卡片出现；tsc 类型检查通过。
- **受影响文件**：
  - `src/lib/utils.ts`（新增 `generateId()` 工具函数）
  - `src/app/(dashboard)/settings/page.tsx`（`crypto.randomUUID()` → `generateId()`）
