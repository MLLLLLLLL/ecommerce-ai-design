# 电商AI设计工作台 - 产品需求文档（PRD）

## 1. 产品概述

### 1.1 产品定位
面向电商设计师和运营人员的AI驱动设计工作台，提供从创意生成到素材管理的一站式解决方案。

### 1.2 产品愿景
让电商设计工作更高效、更智能，通过AI能力降低设计门槛，提升创作效率。

### 1.3 核心价值
- **降低成本**：减少对专业设计师的依赖
- **提升效率**：自动化生成商品图、营销素材
- **激发创意**：AI辅助创作，快速验证设计想法
- **流程化**：工作流编排实现批量化、标准化生产

---

## 2. 目标用户

### 2.1 用户画像

**主要用户：电商设计师**
- 年龄：25-35岁
- 场景：日常需要制作大量商品主图、详情页、营销海报
- 痛点：重复劳动多、创意枯竭、效率要求高
- 需求：快速生成设计素材、批量处理、素材复用

**次要用户：电商运营人员**
- 年龄：22-40岁
- 场景：节日活动、促销海报、商品上新
- 痛点：不会专业设计工具、依赖设计师、响应慢
- 需求：简单易用、模板化、快速出图

### 2.2 使用场景
1. **商品主图生成**：输入商品描述，生成多款主图方案
2. **详情页制作**：利用画布拼接多张AI生成的场景图
3. **营销海报**：节日/促销活动的快速设计
4. **商品场景图**：将商品放入不同使用场景
5. **批量处理**：通过工作流批量生成同类商品素材

---

## 3. 功能需求

### 3.1 核心功能模块

#### 3.1.1 文生图（Text-to-Image）

**功能描述**
用户输入文字描述，AI生成对应图片。

**详细需求**
- 支持中英文提示词输入
- 提供提示词优化建议
- 支持负面提示词（排除不想要的元素）
- 参数配置：
  - 图片尺寸（预设电商常用尺寸：800x800、1200x1200、详情页750宽等）
  - 生成数量（1-4张）
  - 风格选择（写实、插画、3D等）
  - 质量/步数控制
- 生成历史记录
- 一键保存到资源库

**电商场景优化**
- 预设模板提示词：
  - "商品主图模板"
  - "白底干净背景"
  - "场景图模板"
  - "模特展示"
- 智能识别商品类型，推荐合适风格

---

#### 3.1.2 图生图（Image-to-Image）

**功能描述**
基于已有图片，通过AI进行再创作或风格转换。

**详细需求**
- 上传参考图片
- 调整相似度参数（0-1）
- 支持功能：
  - **风格迁移**：将商品图转换为不同艺术风格
  - **背景替换**：保留主体，更换背景
  - **局部重绘**：框选区域进行AI修改
  - **图片扩展**：向外延伸图片内容
  - **超分辨率**：提升图片清晰度
- 支持蒙版编辑（画笔涂抹需要修改的区域）

**电商场景优化**
- 快速去背景
- 商品换背景（纯色/渐变/场景）
- 模特换装
- 商品变体生成（换颜色、换材质）

---

#### 3.1.3 无限画布（Infinite Canvas）

**功能描述**
提供自由排版空间，支持多素材拼接、编辑、导出。

**详细需求**

**画布功能**
- 无限缩放、拖拽
- 网格/参考线辅助
- 图层管理（上下层级调整）
- 多选、群组
- 对齐工具（左对齐、居中、分布等）

**素材操作**
- 拖拽添加图片
- 自由变换（移动、缩放、旋转、裁剪）
- 透明度调整
- 滤镜效果（亮度、对比度、饱和度等）
- 添加文字（字体、大小、颜色、描边、阴影）
- 添加形状（矩形、圆形、线条）

**导出功能**
- 导出整个画布或选中区域
- 格式支持：PNG、JPG、WebP
- 尺寸自定义
- 批量导出多个画板

**特色功能**
- AI抠图集成（右键快速去背景）
- 从资源库快速拖入素材
- 保存为模板供后续复用

---

#### 3.1.4 工作流编排（Workflow）

**功能描述**
类似ComfyUI的节点式工作流，实现自动化批量处理。

**节点类型（预计20种）**

**输入节点（3种）**
1. **文本输入**：手动输入或批量导入文本
2. **图片输入**：上传单张/多张图片
3. **资源库输入**：从本地资源库选择

**AI处理节点（6种）**
4. **文生图节点**：连接各AI服务
5. **图生图节点**：图片转换
6. **图片放大节点**：超分辨率
7. **抠图节点**：背景移除
8. **风格转换节点**：艺术风格化
9. **智能裁剪节点**：按比例智能裁切

**图片处理节点（5种）**
10. **调色节点**：亮度/对比度/饱和度
11. **滤镜节点**：预设滤镜效果
12. **合成节点**：多图层合成
13. **水印节点**：批量添加水印/logo
14. **尺寸调整节点**：批量改变尺寸

**文字处理节点（2种）**
15. **文字渲染节点**：将文字渲染到图片
16. **模板填充节点**：变量替换（如商品名、价格）

**逻辑控制节点（3种）**
17. **条件分支节点**：if-else逻辑
18. **循环节点**：遍历数组批量处理
19. **随机选择节点**：从多个分支随机选一个

**输出节点（1种）**
20. **保存节点**：保存到资源库或导出文件

**工作流功能**
- 可视化节点连接
- 参数面板配置
- 实时预览（查看中间结果）
- 运行/暂停/停止控制
- 错误提示和日志
- 保存/加载工作流模板
- 工作流分享（导出JSON）

**典型工作流示例**
```
文本输入(商品名列表) → 循环节点 → 
  → 模板填充("高端{商品名}产品展示") → 文生图 → 
  → 智能裁剪(1:1) → 水印节点 → 保存到资源库
```

---

#### 3.1.5 资源库（Asset Library）

**功能描述**
本地存储用户生成的所有素材，支持管理和检索。

**存储方案**
- 单用户存储上限：5GB
- 本地文件系统存储
- 数据库记录元数据

**组织管理**
- **文件夹**：多级目录结构
- **标签系统**：
  - 自定义标签
  - 多标签支持
  - 标签颜色标记
- **分类**：
  - 按类型（文生图、图生图、画布导出、工作流输出）
  - 按时间（今天、近7天、本月、自定义）
  - 按尺寸（方图、横图、竖图）
  - 按来源（AI模型区分）

**搜索功能**
- 全文搜索（文件名、标签、描述）
- 高级筛选：
  - 组合条件（类型+标签+日期）
  - 尺寸过滤
  - 文件大小过滤
- 智能搜索：
  - AI识别图片内容（后期功能）
  - 以图搜图（后期功能）

**素材操作**
- 预览（大图查看）
- 重命名
- 添加描述
- 批量打标签
- 移动到文件夹
- 复制/删除
- 导出到本地
- 查看元数据（生成参数、提示词等）

**特色功能**
- 收藏夹（快速访问常用素材）
- 使用记录（查看素材被哪些项目使用）
- 空间监控（存储空间占用提示）
- 批量清理（删除重复/低质量图片）

---

### 3.2 基础功能模块

#### 3.2.1 用户配置

**API Key管理**
- 支持配置多个AI服务：
  - 阿里百炼（通义千问）
  - OpenAI（DALL-E、GPT）
  - 自定义中转站API
- 加密存储本地
- 测试连接功能
- 余额查询（如果API支持）

**个人偏好设置**
- 默认AI服务选择
- 默认图片尺寸
- 界面语言（中文/英文）
- 主题（亮色/暗色）
- 快捷键自定义

**数据管理**
- 导出所有配置
- 导入配置
- 清空缓存
- 重置设置

---

#### 3.2.2 项目管理

**项目功能**
- 创建项目（如"双十一大促"、"春季新品"）
- 项目内包含：
  - 关联的工作流
  - 关联的画布文件
  - 关联的素材
- 项目归档/删除

---

#### 3.2.3 历史记录

**生成历史**
- 记录所有AI生成请求
- 查看历史提示词
- 重新生成（使用相同参数）
- 对比不同版本

---

### 3.3 非功能需求

#### 3.3.1 性能要求
- 画布操作流畅（60fps）
- 工作流执行支持并发（最多5个节点同时运行）
- 资源库加载（1000张图片列表）< 2秒
- 搜索响应时间 < 500ms

#### 3.3.2 可用性要求
- 支持Windows/Mac/Linux
- 支持主流浏览器（Chrome、Edge、Firefox）
- 响应式设计（最小分辨率1366x768）
- 快捷键支持

#### 3.3.3 安全性要求
- API Key本地加密存储
- 不上传用户素材到服务器
- 文件操作权限控制

#### 3.3.4 扩展性要求
- 插件系统（后期支持第三方节点）
- API服务易于扩展
- 数据库易于迁移到云端

## 4. 产品路线图

### Phase 1 - MVP（最小可行产品）
**周期：8-10周**
- ✅ 基础架构搭建
- ✅ 文生图功能（对接OpenAI/阿里百炼）
- ✅ 简单资源库（列表展示、文件夹）
- ✅ 基础API Key配置

### Phase 2 - 核心功能
**周期：6-8周**
- ✅ 图生图功能
- ✅ 无限画布（基础版）
- ✅ 资源库完整功能（搜索、标签、分类）
- ✅ 用户配置完善

### Phase 3 - 高级功能
**周期：8-10周**
- ✅ 工作流编排（20种节点）
- ✅ 条件分支和循环
- ✅ 工作流模板库
- ✅ 画布高级功能（图层、滤镜）

### Phase 4 - 优化增强
**周期：4-6周**
- 性能优化
- 用户体验优化
- 更多AI服务接入
- 插件系统基础
